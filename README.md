## Overview

This project is my personal developer portfolio. It presents my background, selected projects, contact information, and developer identity through a modern React interface with motion-focused interactions.

The implementation uses GSAP and Locomotive Scroll for animation and scrolling effects, with Sass for styling and Vite for the development/build workflow.

## Main Sections

The current component structure includes:

- Hero
- Navbar
- About
- Projects
- Contact
- Footer
- Preloader

## Tech Stack

| Area | Technology |
| --- | --- |
| UI | React 18 |
| Animation | GSAP |
| Scrolling | Locomotive Scroll |
| Styling | Sass |
| Icons | Phosphor Icons |
| Contact | EmailJS |
| Tooling | Vite |

## Local Development

### 1. Clone

```bash
git clone https://github.com/harunhira69/portfolio-harun.git
cd portfolio-harun
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

### 4. Build

```bash
npm run build
```

### 5. Preview production build

```bash
npm run preview
```
